# Карточки с фирменными мазками — v4

Два макета 1200×1600: тёмный и светлый. Фон сгенерирован встроенным imagegen по стилю баннера 3sta.ru, без колеса и текста. Промпт — background-prompt-v4.txt. Готовый прозрачный фон используется повторно; при массовой сборке генерация не нужна.

Шина взята из исходного фото, фон удалён скриптом, товар увеличен с сохранением пропорций и выходит за правый и нижний край карточки. Бренд, модель, размер, индекс нагрузки и скорости берутся из JSON. Логотип магазина исходный; на тёмной версии тёмные элементы белые.

**Бренд Continental, модель WinterContact TS 870, размер и индексы в примере условные. Они не устанавливались по фото и не описывают подтверждённый товар. Перед публикацией замените все поля достоверными данными.**

## Запуск

Python 3.10+, Pillow и NumPy. Нужны шрифты DejaVu Sans (в Linux пакет fonts-dejavu-core). Для другой ОС измените пути FONT и BOLD в branded.py.

```sh
pip install -r requirements.txt
python banner_card.py assets/example.png --data demo-v4.json --theme all
python banner_card.py /path/to/photos --data products.json --theme dark --output /path/to/results
```

Темы: dark, light, all. `--background` позволяет подставить другой PNG-фон. В этом прототипе подпись сезонности — «Зимние шины».

Один товар: обычный JSON-объект с полями brand, model, size, diameter, load, speed. Для папки:

```json
{
  "tyre-001.png": {
    "brand": "Continental",
    "model": "WinterContact TS 870",
    "size": "205/55",
    "diameter": "R16",
    "load": "91",
    "speed": "H"
  }
}
```

Папка обрабатывается без вложенных папок; форматы PNG/JPG/JPEG/WebP. Имена без расширения должны различаться. Повторный запуск перезаписывает результаты в папке вывода, исходники сохраняются. Фото рассчитаны на белый однородный фон. Для более длинной модели или другой геометрии шины просмотрите результат; кадрирование задаётся размером 1390 и координатами (398,610) в compose.
