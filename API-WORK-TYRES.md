# Генерация карточек: грузовые, сельхоз и спецтехника

Базовый адрес: `https://tools.3sta.ru`. Все методы `/api/v1/cards` требуют заголовок `X-API-Key` с ключом нашего сервиса (не ключом Ozon).

## Создать или перегенерировать карточку

```http
POST https://tools.3sta.ru/api/v1/cards/generate
X-API-Key: YOUR_CARD_API_KEY
Content-Type: application/json
```

```json
{
  "product_type": "truck",
  "theme": "dark",
  "sku": "T587344",
  "brand": "LongMarch",
  "model": "LM511",
  "size": "7.00R16",
  "application": "Ведущая",
  "ply_rating": "14 PR",
  "construction": "Радиальная",
  "equipment": "TL",
  "load_index": "118",
  "speed_index": "J",
  "image_url": "https://ir.ozone.ru/s3/multimedia-1-r/wc2500/9021536703.jpg"
}
```

Используйте свои артикул, параметры и исходное фото. Картинка должна содержать фотографию шины, а не готовую карточку с надписями.

### Тип товара

| `product_type` | Категория | Заголовок карточки |
| --- | --- | --- |
| `truck` | Грузовая | ГРУЗОВЫЕ ШИНЫ |
| `agricultural` | Сельхоз | СЕЛЬХОЗ ШИНЫ |
| `special` | Спецтехника | ШИНЫ ДЛЯ СПЕЦТЕХНИКИ |

**Для сельхозки** замените `product_type` на `agricultural`. **Для спецтехники** — на `special`. Остальные поля имеют тот же формат. Используется общий грузовой шаблон с соответствующим заголовком. Тип передаётся явно: по бренду или размеру он не определяется. Без поля применяется прежний легковой режим `passenger` с обязательными индексами и проверкой легкового размера.

### Поля запроса

| Поле | Обязательно | Описание |
| --- | --- | --- |
| `product_type` | Да для этих категорий | `truck`, `agricultural`, `special` |
| `theme` | Да | `dark` — тёмная; `light` — белая |
| `sku` | Да | Артикул, 1–100 латинских букв, цифр, `_` или `-`; служебные имена Windows запрещены |
| `brand` | Да | Бренд, до 100 символов |
| `model` | Да | Модель, до 200 символов |
| `size` | Да | Свободная запись размера, до 180 символов: `11.00R20`, `18.4-26`, `12-16.5 NHS` |
| `image_url` | Да | Публичная HTTP/HTTPS-ссылка на исходное JPEG, PNG или WebP |
| `diameter` | Нет | Диаметр вручную, до 80 символов; например `R20`. Если не указан, выделяется из размера; неоднозначный размер показывается целиком |
| `application` | Нет | Применяемость, до 160 символов |
| `ply_rating` | Нет | Слойность, до 80 символов, например `14 PR` |
| `construction` | Нет | Конструкция, до 120 символов |
| `equipment` | Нет | Комплектация, до 120 символов, например `TL` или `TTF` |
| `load_index` | Нет | Строка из 2–3 цифр, допускается двойной индекс: `150/148` |
| `speed_index` | Нет | 1–3 латинские буквы: `J`, `K` и т. д. |

Пустые необязательные поля опускайте или передавайте `null`: соответствующий блок не рисуется. `season` относится к легковому шаблону и здесь не используется. Неизвестные поля/типы возвращают `422`.

### Ответ

```json
{
  "sku": "T587344",
  "theme": "dark",
  "product_type": "truck",
  "image_url": "https://tools.3sta.ru/images/truck/dark/T587344.jpg?v=123"
}
```

Генерация синхронная: `200` означает готовое изображение. Настройте ожидание клиента до 180 секунд. По умолчанию результат — компактный JPG 900×1200. Изображение по `image_url` доступно без ключа. Повторный запрос заменяет карточку с тем же `(product_type, sku, theme)`; не запускайте несколько генераций одного ключа одновременно. Другие типы и темы хранятся отдельно.

## Чтение карточек и параметров

```http
GET /api/v1/cards/T587344?product_type=truck&theme=dark
GET /api/v1/cards/T587344/parameters?product_type=truck&theme=light
GET /api/v1/cards?product_type=agricultural&theme=light&page=1&per_page=100
```

Заголовок `X-API-Key` нужен во всех трёх запросах. Для другой категории меняйте `product_type`; тема обязательна. `page` начинается с 1, `per_page` — 1–500. Параметры при отсутствии у выбранной темы берутся из другой темы того же артикула и типа; выбранная тема в ответе сохраняется.

## Загрузка в Ozon

```http
POST /api/v1/cards/T587344/ozon?product_type=truck&theme=dark
X-API-Key: YOUR_CARD_API_KEY
```

Этот отдельный запрос публикует сохранённую карточку и памятку. В Ozon товар ищется по `offer_id = sku + SU`. Остальные фотографии с третьей сохраняются. Генерация сама не запускает публикацию. Подробности — [OZON.md](OZON.md).

## Основные ошибки

| Код | Причина |
| --- | --- |
| `401` | Неверный или отсутствующий ключ сервиса |
| `404` | Нет карточки, параметров или товара Ozon |
| `413` | Исходное изображение слишком большое |
| `422` | Некорректные поля, ссылка или изображение |
| `429` | Генератор занят; повторить позже |
| `502` | Не удалось скачать исходник или получить ответ внешнего сервиса |
| `503` | Не настроены необходимые ключи |
