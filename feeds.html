Новый фид

Один артикул на строку или через запятую. Используется точное значение id товара в исходном фиде, без автоматического добавления SU. Оставьте пустым, чтобы взять все товары. Если указанный артикул не найден, сборка остановится.

Тип и тема используются для поиска готовых карточек; товары автоматически по ним не фильтруются. При замене фото карточки должны существовать для всех выбранных артикулов. Другие фото сохраняются.

Для последующей генерации изображений выбирайте исходные фотографии: готовая карточка с надписями не подходит как исходник. Сборка фида сама не запускает генерацию картинок и не загружает товары в VK.
