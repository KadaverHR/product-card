# Обновлённая тёмная карточка — v7

Тёмная карточка использует отдельный заново сгенерированный фон dark-paint-background-v7.png: фиолетовые и лаймовые матовые мазки на угольном фоне, без белой краски. Это новый рисунок, а не фильтрация старого. Фон создан встроенным imagegen. Светлая карточка использует прежний paint-background-v4.png.

Запуск и формат JSON описаны в README-v4.md. Дополнительный параметр `--dark-background` задаёт тёмный фон; `--background` теперь задаёт только светлый фон. Мазки не генерируются при массовой сборке — используются готовые файлы.

```sh
python banner_card.py assets/example.png --data demo-v4.json --theme all
```

В примере бренд, модель, размер и индексы условные. Шина — исходное фото пользователя, все тексты и логотипы наложены скриптом.
