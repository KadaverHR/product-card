# API карточек сельхозшин и шин для спецтехники

Документ для интеграции: генерация, получение готовых изображений и выгрузка каталога. Все примеры относятся только к сельхозшинам и спецтехнике.

## Подключение

Базовый адрес: `https://tools.3sta.ru`.

Во всех запросах `/api/v1/cards` передавайте заголовок:

```http
X-API-Key: YOUR_CARD_API_KEY
```

Ключ выдаёт владелец сервиса. Это ключ генератора карточек, не ключ Ozon. Для JSON-запросов также нужен `Content-Type: application/json`. Готовые изображения по возвращённым ссылкам доступны без ключа.

| Параметр | Значения |
| --- | --- |
| `product_type` | `agricultural` — сельхоз; `special` — спецтехника |
| `theme` | `dark` — тёмная; `light` — светлая |

Всегда указывайте тип явно: без `product_type` API использует легковые шины. Для генерации тип и тема передаются в JSON, для чтения — в query-параметрах.

## 1. Сгенерировать сельхозкарточку

```http
POST https://tools.3sta.ru/api/v1/cards/generate
X-API-Key: YOUR_CARD_API_KEY
Content-Type: application/json
```

```json
{
  "product_type": "agricultural",
  "theme": "dark",
  "sku": "AGRO001",
  "brand": "Trelleborg",
  "model": "IM110",
  "size": "7.50-16",
  "ply_rating": "8 PR",
  "construction": "Диагональная",
  "equipment": "TL",
  "load_index": "112",
  "speed_index": "A8",
  "image_url": "https://example.com/original-agricultural-tyre.jpg"
}
```

Ссылки `example.com` в примерах — заглушки: замените их прямыми публичными ссылками на реальные исходные фотографии. Используйте свои артикулы и характеристики товаров.

## 2. Сгенерировать пневматическую шину для спецтехники

Тот же метод `POST /api/v1/cards/generate`, тело запроса:

```json
{
  "product_type": "special",
  "theme": "light",
  "sku": "SPEC001",
  "brand": "BKT",
  "model": "SKID POWER",
  "size": "12-16.5",
  "ply_rating": "10 PR",
  "construction": "Диагональная",
  "equipment": "TL",
  "image_url": "https://example.com/original-special-tyre.jpg"
}
```

Для пневматической шины отдельный флаг не нужен. Передайте известные характеристики, поле `features` можно опустить.

## 3. Сгенерировать цельнолитую шину

Тот же метод, тело запроса:

```json
{
  "product_type": "special",
  "theme": "dark",
  "sku": "SOLID001",
  "brand": "Trelleborg",
  "model": "M2 NM",
  "size": "7.50-15",
  "features": "Цельнолитая",
  "image_url": "https://example.com/original-solid-tyre.jpg"
}
```

Укажите `features: "Цельнолитая"`. Особенность выводится отдельной акцентной плашкой. Если другие характеристики и индексы отсутствуют, шина показывается крупнее и ближе к центру. Цвет исходной цельнолитой шины сохраняется. Другие особенности, например `Немаркая`, сами по себе не включают режим цельнолитой шины; при необходимости передайте `Цельнолитая, немаркая`.

## Поля генерации

Все значения характеристик передаются строками. Неизвестные поля запрещены.

| Поле | Обязательно | Формат |
| --- | --- | --- |
| `product_type` | Да для этих категорий | `agricultural` или `special` |
| `theme` | Да | `dark` или `light` |
| `sku` | Да | 1–100 латинских букв, цифр, `_`, `-`; служебные имена Windows запрещены |
| `brand` | Да | Бренд, 1–100 символов |
| `model` | Да | Модель, 1–200 символов |
| `size` | Да | Размер, 1–180 символов, свободная запись |
| `image_url` | Да | Публичная прямая HTTP/HTTPS-ссылка на JPEG, PNG или WebP |
| `diameter` | Нет | Диаметр вручную, до 80 символов, например `16.5` или `R20` |
| `application` | Нет | Применяемость, до 160 символов |
| `ply_rating` | Нет | Слойность, до 80 символов, например `10 PR` |
| `construction` | Нет | Конструкция, до 120 символов, например `Диагональная` |
| `equipment` | Нет | Комплектация, до 120 символов: `TL`, `TT`, `TTF` и т. п. |
| `features` | Нет | Особенности, до 200 символов |
| `load_index` | Нет | 2–3 цифры или двойной индекс: `112`, `150/148` |
| `speed_index` | Нет | 1–3 латинские буквы или `A1`–`A8`: `J`, `K`, `A8` |

Отсутствующие необязательные поля опускайте или передавайте `null`. API не придумывает характеристики: соответствующие блоки не рисуются. `season` для этих категорий не используется.

Размеры, например `7.50-16`, `12-16.5 NHS`, `18.4R38`, передаются исходной строкой. Диаметр выделяется автоматически; при неоднозначном формате размер может отображаться целиком. Для точного разделения передайте `diameter` отдельно. Дефис остаётся в основной части размера; `R` автоматически не добавляется.

Исходник должен содержать фотографию шины, а не готовую карточку с текстом. Белый/светло-серый фон и светлая середина удаляются автоматически, но качество результата зависит от исходного фото. Максимум: 30 МБ и 20 мегапикселей. Ссылка должна открываться без авторизации на стандартном HTTP/HTTPS-порту.

## Ответ генератора и повторная генерация

Успех — `200 OK`:

```json
{
  "sku": "AGRO001",
  "theme": "dark",
  "image_url": "https://tools.3sta.ru/images/agricultural/dark/AGRO001.jpg?v=123456789",
  "product_type": "agricultural"
}
```

Генерация синхронная: при получении `200` изображение уже готово. Рекомендуемый таймаут клиента — 180 секунд. По умолчанию результат — компактный JPEG 900×1200; параметры сжатия задаёт владелец сервера, передавать их в JSON не нужно.

Повторный POST с тем же `(product_type, sku, theme)` заменяет карточку и сохраняет переданные параметры. Это полный запрос генерации, не частичное обновление: передавайте все необходимые поля. Другие темы и типы не перезаписываются. Для второй темы повторите запрос с другим `theme`. Не запускайте параллельно генерацию одного и того же ключа.

Используйте `image_url` из ответа целиком, включая `?v=...`: версия меняется после перегенерации. Не собирайте URL самостоятельно.

## 4. Получить готовую карточку

```http
GET https://tools.3sta.ru/api/v1/cards/AGRO001?product_type=agricultural&theme=dark
X-API-Key: YOUR_CARD_API_KEY
```

Ответ такой же, как у генератора. Для спецтехники используйте `product_type=special`. Если карточки нет — `404`; этот GET не запускает генерацию. Полученный `image_url` можно открыть или скачать обычным GET без ключа.

## 5. Прочитать параметры для редактирования

```http
GET https://tools.3sta.ru/api/v1/cards/SPEC001/parameters?product_type=special&theme=light
X-API-Key: YOUR_CARD_API_KEY
```

Возвращается сохранённый JSON параметров генерации. Если у выбранной темы параметров нет, API попробует другую тему того же артикула и типа. В ответе будет запрошенный `theme`; само изображение второй темы при этом не создаётся. Если параметры отсутствуют — `404`.

Для редактирования: получите параметры → измените нужные поля → отправьте полный JSON в `POST /api/v1/cards/generate`.

## 6. Выгрузить готовые карточки с пагинацией

```http
GET https://tools.3sta.ru/api/v1/cards?product_type=special&theme=dark&page=1&per_page=100
X-API-Key: YOUR_CARD_API_KEY
```

`page` — от 1, по умолчанию 1. `per_page` — от 1 до 500, по умолчанию 100. Тема обязательна.

```json
{
  "theme": "dark",
  "product_type": "special",
  "total": 1,
  "count": 1,
  "items": [
    {
      "sku": "SPEC001",
      "theme": "dark",
      "image_url": "https://tools.3sta.ru/images/special/dark/SPEC001.jpg?v=123456789",
      "product_type": "special"
    }
  ],
  "pagination": {
    "page": 1,
    "per_page": 100,
    "total_pages": 1,
    "has_next_page": false
  }
}
```

Увеличивайте `page`, пока `has_next_page` не станет `false`. Выгружайте каждый тип и тему отдельно. Пустой каталог или страница за пределами каталога возвращают `200` и `items: []`; для пустого каталога `total_pages: 0`. При изменении каталога между запросами состав страниц может меняться: устраняйте дубли по `(product_type, sku, theme)` и повторяйте сверку после массовой генерации.

## Ошибки и повторы

| HTTP | Что делать |
| --- | --- |
| `401` | Проверить `X-API-Key` |
| `404` | Нет карточки/параметров для выбранных артикула, типа и темы |
| `413` | Уменьшить исходник: превышен размер файла или число пикселей |
| `422` | Исправить поля запроса или исходное изображение; посмотреть `detail` |
| `429` | Генератор занят; повторить с задержкой и увеличением интервала |
| `500` | Ошибка генерации; передать владельцу сервиса артикул, тип, тему и время запроса |
| `502` | Не удалось скачать исходник; проверить доступность и формат ссылки |
| `503` | На сервере не настроен ключ API; обратиться к владельцу |

Ошибки сервиса обычно содержат `detail: {"code": "...", "message": "..."}`; ошибки проверки JSON — массив объектов в `detail`. При сетевом таймауте сначала запросите готовую карточку и параметры: генерация могла завершиться после разрыва соединения. Наличие изображения само по себе не доказывает выполнение последнего запроса, если карточка существовала раньше.

## Работа через браузер

Общий редактор: `https://tools.3sta.ru/cards/viewer`. Выберите «Сельхоз» или «Спецтехника», тему и артикул. Страница позволяет просмотреть карточку, изменить параметры и запустить генерацию. Внешняя интеграция использует описанный выше API с ключом.

Генерация не публикует изображения на маркетплейсе автоматически. Загрузка в Ozon выполняется отдельно; для получения и генерации карточек ключи Ozon не нужны.
