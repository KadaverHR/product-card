# API карточек товаров — инструкция для разработчиков

## Подключение

Базовый адрес: **https://tools.3sta.ru**.

Сервис позволяет получать готовые карточки по артикулу, выгружать каталог с пагинацией и создавать изображения из переданных характеристик и фотографии товара. Генератор создаёт PNG **1200×1600 пикселей**, пропорция 3:4.

Для всех запросов `/api/v1/cards` передавайте заголовок:

```http
X-API-Key: YOUR_API_KEY
```

Ключ выдаётся владельцем сервиса отдельно. Храните его на своей серверной стороне, не в публичном JavaScript и не в репозитории. Это API key, не Bearer-токен. Значение `YOUR_API_KEY` в примерах — заглушка.

Готовые PNG доступны по возвращённым ссылкам **без ключа**. JSON-запросы отправляйте в UTF-8 с `Content-Type: application/json`.

Темы: `light` — светлая, `dark` — тёмная. Значение `all` не поддерживается; для двух тем выполните два запроса. Артикул передаётся в поле или параметре `sku`, регистр важен.

Интерактивная документация: https://tools.3sta.ru/cards/docs. Схема OpenAPI: https://tools.3sta.ru/openapi.json.

## 1. Получить готовую карточку по артикулу

```http
GET https://tools.3sta.ru/api/v1/cards/S207352?theme=light
X-API-Key: YOUR_API_KEY
```

`theme` обязателен. Пример ответа `200 OK`:

```json
{
  "sku": "S207352",
  "theme": "light",
  "image_url": "https://tools.3sta.ru/images/light/S207352.png?v=123"
}
```

Откройте `image_url` обычным GET-запросом — получите PNG с `Content-Type: image/png`. Можно скачать его к себе или использовать URL в `<img src="…">`. Ключ при скачивании изображения не передавайте.

Если карточка отсутствует, ответ `404`:

```json
{
  "detail": {
    "code": "image_not_found",
    "message": "Картинка для этого артикула и темы не сгенерирована"
  }
}
```

Этот GET не запускает генерацию автоматически. Для создания используйте метод из раздела 3.

## 2. Получить каталог изображений с пагинацией

```http
GET https://tools.3sta.ru/api/v1/cards?theme=light&page=1&per_page=100
X-API-Key: YOUR_API_KEY
```

| Параметр | Обязательный | Значение |
| --- | --- | --- |
| `theme` | Да | `light` или `dark` |
| `page` | Нет | Целое число от 1; по умолчанию `1` |
| `per_page` | Нет | От 1 до 500; по умолчанию `100` |

Пример ответа `200 OK`:

```json
{
  "theme": "light",
  "total": 2,
  "count": 2,
  "items": [
    {
      "sku": "S207352",
      "theme": "light",
      "image_url": "https://tools.3sta.ru/images/light/S207352.png?v=123"
    },
    {
      "sku": "S207353",
      "theme": "light",
      "image_url": "https://tools.3sta.ru/images/light/S207353.png?v=456"
    }
  ],
  "pagination": {
    "page": 1,
    "per_page": 100,
    "total_pages": 1,
    "has_next_page": false
  }
}
```

`total` — общее число карточек выбранной темы; `count` — количество на текущей странице. `items` отсортированы по артикулу.

Для полной выгрузки начните с `page=1`, сохраняйте элементы и увеличивайте страницу, пока `pagination.has_next_page` равно `true`. Темы выгружайте отдельно. Параметры `limit` и `offset` не используются.

Пустой каталог или страница за пределами каталога возвращают `200` и `items: []`; для пустого каталога `total_pages: 0`. Во время массовой генерации каталог меняется, поэтому страницы не являются фиксированным снимком. При синхронизации используйте ключ `(sku, theme)` для устранения дублей; для полной сверки повторите выгрузку после окончания генерации.

## 3. Создать или перегенерировать карточку

```http
POST https://tools.3sta.ru/api/v1/cards/generate
X-API-Key: YOUR_API_KEY
Content-Type: application/json
```

Тело запроса:

```json
{
  "theme": "light",
  "sku": "S207352",
  "brand": "Cordiant",
  "model": "GRAVITY SUV",
  "size": "225/65 R17",
  "load_index": "106/104",
  "speed_index": "H",
  "image_url": "https://example.com/product-photo.jpg",
  "season": "summer"
}
```

Замените `image_url` на реальную, доступную сервису ссылку на фото. URL из примера условный.

| Поле | Обязательное | Формат |
| --- | --- | --- |
| `theme` | Да | `light` или `dark` |
| `sku` | Да | 1–100 латинских букв, цифр, `_` или `-` |
| `brand` | Да | Непустая строка до 100 символов |
| `model` | Да | Непустая строка до 200 символов |
| `size` | Да | Полный размер без индексов, например `225/65 R17`: 3 цифры, `/`, 2–3 цифры, пробел, `R` или `r`, 2 цифры |
| `load_index` | Да | Строка из 2–3 цифр или две такие группы через `/`, например `102/104` |
| `speed_index` | Да | 1–3 латинских буквы, например `H`, `V`, `ZR` |
| `image_url` | Да | Публичная HTTP/HTTPS ссылка на исходное фото JPEG, PNG или WebP |
| `season` | Нет | `summer`, `winter`, `all-season` или `null` |

Все индексы передавайте **строками**, не числами. Неизвестные поля отклоняются. Для `sku` запрещены имена `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9` независимо от регистра.

Сезон задаёт подпись: `summer` → «ЛЕТНИЕ ШИНЫ», `winter` → «ЗИМНИЕ ШИНЫ», `all-season` → «ВСЕСЕЗОННЫЕ ШИНЫ». Если поле отсутствует или равно `null`, подпись — «ШИНЫ».

### Результат

Генерация **синхронная**: запрос ждёт скачивания фото и сборки изображения. Нет отдельного задания, webhook или метода проверки прогресса. Для клиента задайте тайм-аут порядка **180 секунд**.

Ответ `200 OK`:

```json
{
  "sku": "S207352",
  "theme": "light",
  "image_url": "https://tools.3sta.ru/images/light/S207352.png?v=789"
}
```

В запросе `image_url` — **исходная фотография**, в ответе — **готовая карточка**. Ответ содержит URL, не Base64 и не бинарное изображение.

SKU не обязан заранее существовать в каталоге. Повторный POST заменяет карточку с той же парой `(sku, theme)`, другая тема не меняется. Не запускайте одновременно несколько генераций одной пары. Пакетное обновление каталога владельцем сервиса может впоследствии перезаписать карточку данными фида.

Параметр `v` меняется после обновления файла и помогает обойти кеш. Сохраняйте полный URL из последнего ответа. Это не ссылка на архивную версию: даже старый URL отдаёт текущий файл.

## 4. Получить параметры для повторной генерации

```http
GET https://tools.3sta.ru/api/v1/cards/S207352/parameters?theme=light
X-API-Key: YOUR_API_KEY
```

Пример ответа `200 OK`:

```json
{
  "sku": "S207352",
  "theme": "light",
  "brand": "Cordiant",
  "model": "GRAVITY SUV",
  "size": "225/65 R17",
  "load_index": "106/104",
  "speed_index": "H",
  "image_url": "https://example.com/product-photo.jpg",
  "season": "summer"
}
```

Измените нужные поля и отправьте объект в `POST /api/v1/cards/generate`. `image_url` здесь — исходное фото.

Метод возвращает последние сохранённые ручные параметры для выбранной темы, а при их отсутствии — параметры из фида. В данных фида возможны пустые значения: проверьте и заполните обязательные поля перед генерацией. При отсутствии параметров — `404`, `parameters_not_found`. Готовая карточка и параметры могут существовать независимо друг от друга. Параметры не гарантируют описание текущего PNG, если он был перезаписан массовой обработкой фида.

## 5. Ошибки и ограничения

| HTTP | Причина | Действие клиента |
| --- | --- | --- |
| `401` | Ключ отсутствует или неверен | Проверить `X-API-Key` |
| `404` | Нет изображения или параметров | Проверить SKU и тему; при необходимости передать данные для генерации |
| `413` | Фото больше 30 МиБ (31 457 280 байт) или 20 000 000 пикселей | Уменьшить исходное фото |
| `422` | Ошибка полей, запрещённая ссылка, неверный формат фото или не удалось выделить товар | Исправить данные, не повторять тот же запрос без изменений |
| `429` | Две генерации уже выполняются | Повторить позже с увеличивающейся задержкой |
| `500` | Ошибка генерации, сохранения или чтения параметров | Проверить текущую карточку и сообщить владельцу сервиса |
| `502` | Не удалось скачать фото или превышен лимит перенаправлений | Проверить доступность исходной фотографии |
| `503` | API-ключ не настроен на стороне сервиса | Обратиться к владельцу сервиса |

Пример прикладной ошибки:

```json
{
  "detail": {
    "code": "unauthorized",
    "message": "Invalid or missing X-API-Key"
  }
}
```

У ошибок проверки полей `detail` — массив, а не объект:

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "sku"],
      "msg": "Field required",
      "input": {}
    }
  ]
}
```

Обрабатывайте оба формата. Ответы прокси при сетевых ошибках могут быть не JSON.

Исходное фото должно скачиваться без cookies, дополнительных заголовков и авторизации. Разрешены публичные адреса и порты 80/443; внутренние адреса запрещены, в том числе после перенаправления. Разрешено до 5 переходов. Бюджет скачивания — 30 секунд с проверками между чтениями; это не гарантия общего времени генерации. Лучше передавать фото на белом фоне.

Сервис допускает две одновременные генерации на процесс. Общего лимита запросов на чтение в приложении нет, но клиенту следует избегать избыточного параллелизма.

При тайм-ауте клиента сервер мог продолжить обработку. Не повторяйте POST немедленно: сначала проверьте карточку через GET. Обновление PNG и сохранение параметров — отдельные операции, поэтому `500` не гарантирует, что изображение осталось прежним. API не предоставляет idempotency key или историю версий.

## 6. Примеры запросов

### cURL: получить ссылку

```bash
curl --fail-with-body \
  -H "X-API-Key: YOUR_API_KEY" \
  'https://tools.3sta.ru/api/v1/cards/S207352?theme=light'
```

### cURL: создать карточку

```bash
curl --fail-with-body --max-time 180 \
  -X POST 'https://tools.3sta.ru/api/v1/cards/generate' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  --data '{
    "theme": "light",
    "sku": "S207352",
    "brand": "Cordiant",
    "model": "GRAVITY SUV",
    "size": "225/65 R17",
    "load_index": "106/104",
    "speed_index": "H",
    "image_url": "https://example.com/product-photo.jpg",
    "season": "summer"
  }'
```

Замените ключ и ссылку на фото своими значениями. Перед запуском генерации учтите: существующая карточка этого SKU и темы будет перезаписана.

### Postman

1. Создайте переменные окружения `base_url = https://tools.3sta.ru` и `api_key` с выданным ключом. Не включайте реальный ключ в экспортируемую коллекцию.
2. Для поиска: **GET** `{{base_url}}/api/v1/cards/S207352?theme=light`.
3. В **Headers** задайте `X-API-Key: {{api_key}}`.
4. Для генерации: **POST** `{{base_url}}/api/v1/cards/generate`, **Body → raw → JSON**; вставьте тело из раздела 3 с реальным URL фото. Заголовок ключа оставьте.
5. Из ответа скопируйте `image_url` и выполните отдельный **GET** без ключа, чтобы посмотреть или скачать PNG.

## Рекомендуемый сценарий интеграции

Для показа карточки: запросить её по `(sku, theme)` → получить `image_url` → скачать или показать PNG. При `404` генерацию запускает ваш код явным POST, если у него есть необходимые данные.

Для редактирования: получить параметры → изменить поля → выполнить POST генерации → сохранить новый `image_url`.

Для синхронизации каталога: пройти страницы каждой темы → обновить у себя записи по `(sku, theme)` → использовать полный URL с актуальным `v`.

Публичный редактор https://tools.3sta.ru/cards/viewer предназначен для ручной работы. Он доступен без авторизации, включая перегенерацию; его служебный POST также публичный. Для программной интеграции используйте документированные методы `/api/v1/cards` с ключом.
