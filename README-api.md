# API генерации карточек

Документ для передачи внешним разработчикам: [API-INTEGRATION.md](API-INTEGRATION.md) — получение и генерация изображений, авторизация, пагинация и примеры запросов без инструкций по администрированию сервера.

Базовый адрес: `https://tools.3sta.ru`. Внешние методы этого проекта начинаются с `/api/v1/cards` и не относятся к API `/api/tires` соседнего проекта DEV 3sta.

API возвращает JSON со ссылками на готовые изображения, а не файлы или Base64. Генератор создаёт PNG размером **1200×1600 пикселей** (ширина × высота, пропорция 3:4). Методы чтения отдают уже сохранённые файлы и не проверяют их размеры. Генерация использует фирменный шаблон и настоящее фото товара; ключ сервиса генеративных изображений не нужен. Для внешнего API нужен собственный `X-API-Key`.

Светлая генерация использует `assets/light-paint-background-v8.png`, тёмная — `assets/dark-paint-background-v7.png`. Смена фона не обновляет ранее сохранённые карточки автоматически.

## Методы

| Метод | Путь | Назначение | Авторизация |
| --- | --- | --- | --- |
| GET | `/api/v1/cards?theme=dark&page=1&per_page=100` | Страница готовых карточек | `X-API-Key` |
| GET | `/api/v1/cards/{sku}?theme=dark` | Ссылка на карточку | `X-API-Key` |
| GET | `/api/v1/cards/{sku}/parameters?theme=dark` | Сохранённые параметры | `X-API-Key` |
| POST | `/api/v1/cards/generate` | Создание или перезапись карточки | `X-API-Key` |
| GET | `/images/{theme}/{sku}.png` | Сам PNG-файл | Нет |
| GET / POST | `/cards/viewer` | Страница и операции публичного редактора | Нет |

## Интерфейс просмотра и редактирования

Отдельная страница: `https://tools.3sta.ru/cards/viewer`. Введите артикул и выберите тему. Поиск показывает готовую карточку и подставляет сохранённые параметры. Измените бренд, модель, размер, индексы, сезон или ссылку на исходное фото и нажмите «Перегенерировать изображение».

Параметры загружаются из соседней папки `<CARD_OUTPUT_DIR>-sources/<sku>/`. Если параметров нет, интерфейс позволяет заполнить форму вручную. Подробный контракт защищённого метода получения параметров приведён ниже.

Для доступа к странице добавьте внутри HTTPS-блока Nginx, рядом с `/cards/docs`:

```nginx
location = /cards/viewer {
    proxy_pass http://127.0.0.1:8010;
    include /etc/nginx/proxy_params;
}
```

При генерации через интерфейс заменяется только выбранная тема. Пакетный запуск `feed_card.py` по-прежнему перезаписывает изображения значениями из фида.

## Установка и запуск API

Python 3.10+, терминал в папке проекта:

```powershell
pip install -r requirements.txt
$env:CARD_API_KEY = "your-secret-api-key"
$env:CARD_PUBLIC_BASE_URL = "https://tools.3sta.ru"
python -m uvicorn api:app --host 127.0.0.1 --port 8010 --workers 1
```

Можно хранить `CARD_API_KEY`, адрес и каталог в локальном `.env` и запускать `python -m uvicorn api:app --env-file .env --host 127.0.0.1 --port 8010 --workers 1`. Сам `api.py` не загружает `.env` автоматически. Файл `.env` исключён из Git.

На действующем Ubuntu-сервере проект расположен в `/opt/product-card`, сервис — `product-card.service`, настройки процесса — `/etc/product-card.conf`. Перезапуск: `sudo systemctl restart product-card`. Внутренний адрес — `http://127.0.0.1:8010`; для внешних запросов используйте HTTPS-домен, без порта `8010`.

Сервер работает, пока открыт процесс. Документация на сервере: `https://tools.3sta.ru/cards/docs`; OpenAPI: `/openapi.json`. При прямом запуске документация доступна по `/docs` и `/redoc`.

Для внешнего доступа задайте `CARD_PUBLIC_BASE_URL` равным внешнему адресу, например `https://tools.3sta.ru`. Nginx должен направлять `/api/v1/cards`, `/api/v1/cards/…`, `/images/…` и `/cards/viewer` на `127.0.0.1:8010`. Путь `/cards/docs` проксируется на `/docs`, `/openapi.json` — без изменения пути. Не перенаправляйте весь `/api/` на этот проект: он используется соседним DEV 3sta. Тайм-аут генерации на прокси должен быть около 180 секунд. Используйте один процесс Uvicorn: лимит генерации действует внутри процесса.

| Переменная окружения | По умолчанию | Назначение |
| --- | --- | --- |
| `CARD_API_KEY` | не задан | Ключ внешнего API; без настройки API возвращает `503` |
| `CARD_PUBLIC_BASE_URL` | `https://tools.3sta.ru` | Основа всех возвращаемых ссылок; без `/` на конце |
| `CARD_OUTPUT_DIR` | `<папка проекта>/feed-output` | Каталог карточек с подпапками `dark` и `light` |

Все методы `/api/v1/cards` требуют заголовок `X-API-Key` со значением `CARD_API_KEY`. Неверный или отсутствующий ключ возвращает `401`. Если ключ на сервере не настроен, API возвращает `503`, а не открывает доступ.

Интерфейс `/cards/viewer` и ссылки `/images/` доступны без авторизации. Интерфейс не запрашивает и не получает API-ключ: поиск, загрузка параметров и перегенерация выполняются через отдельный `POST /cards/viewer`. Существующего блока Nginx для `/cards/viewer` достаточно, менять конфигурацию не нужно. Эта страница общедоступна, включая перегенерацию; её операции также можно вызвать программно без ключа.

Для POST с JSON используйте `Content-Type: application/json`. В методах внешнего API тема обязательна: в query-параметре GET или в теле генерации. `dark` — тёмная, `light` — светлая. Значение `all` для API не используется; нужны два запроса. Артикулы чувствительны к регистру.

## 1. Готовые товары по теме с пагинацией

```http
GET /api/v1/cards?theme=dark&page=1&per_page=100
X-API-Key: your-secret-api-key
```

Ответ `200 OK`:

```json
{
  "theme": "dark",
  "total": 2,
  "count": 2,
  "items": [
    {"sku": "S207352", "theme": "dark", "image_url": "https://tools.3sta.ru/images/dark/S207352.png?v=123"},
    {"sku": "S207353", "theme": "dark", "image_url": "https://tools.3sta.ru/images/dark/S207353.png?v=456"}
  ],
  "pagination": {
    "page": 1,
    "per_page": 100,
    "total_pages": 1,
    "has_next_page": false
  }
}
```

Возвращает страницу уже созданных карточек выбранной темы, включая результаты `feed_card.py`. Не читает фид и не запускает генерацию. Список отсортирован по артикулу. Остальные характеристики товара не возвращаются: здесь каталог доступных изображений.

| Параметр | Обязательно | По умолчанию | Значение |
| --- | --- | --- | --- |
| `theme` | да | — | `dark` или `light` |
| `page` | нет | `1` | Номер страницы, целое число от 1 |
| `per_page` | нет | `100` | Количество карточек на странице, от 1 до 500 |

`total` — общее количество готовых карточек выбранной темы, `count` — количество в текущем ответе. `pagination.total_pages` — число страниц, `has_next_page` — есть ли следующая страница. Для последовательной загрузки увеличивайте `page`, пока `has_next_page` равно `true`.

Если изображений нет: `total: 0`, `count: 0`, `items: []`, `total_pages: 0`. Страница за пределами списка возвращает `200` с пустым `items` и `has_next_page: false`. Неверные параметры возвращают `422`.

Запрос без параметров пагинации возвращает только первые 100 карточек. Для получения всего каталога нужно пройти страницы. Используйте именно `page` и `per_page`: `limit` и `offset` этот метод не использует. Состав страниц может изменяться, пока фид создаёт новые файлы; фиксированного снимка каталога нет.

## 2. Карточка по артикулу

```http
GET /api/v1/cards/S207352?theme=light
X-API-Key: your-secret-api-key
```

Ответ `200 OK`:

```json
{
  "sku": "S207352",
  "theme": "light",
  "image_url": "https://tools.3sta.ru/images/light/S207352.png?v=123"
}
```

Если файл для этого артикула и темы отсутствует, ответ `404 Not Found`:

```json
{
  "detail": {
    "code": "image_not_found",
    "message": "Картинка для этого артикула и темы не сгенерирована"
  }
}
```

Этот запрос никогда не генерирует изображение автоматически.

## 3. Сохранённые параметры генерации

```http
GET /api/v1/cards/S207352/parameters?theme=dark
X-API-Key: your-secret-api-key
```

Пример ответа `200 OK`:

```json
{
  "sku": "S207352",
  "theme": "dark",
  "brand": "Cordiant",
  "model": "GRAVITY SUV",
  "size": "225/65 R17",
  "load_index": "106",
  "speed_index": "H",
  "image_url": "https://example.com/photo.jpg",
  "season": "summer"
}
```

Здесь `image_url` — **исходное фото**, а не готовая карточка. Сначала читается `<CARD_OUTPUT_DIR>-sources/<sku>/generation-<theme>.json`, сохранённый при генерации через API или интерфейс. Если его нет, значения берутся из `product.json`, созданного обработчиком фида; фото — первое из `pictures`.

Метод не создаёт изображение и не требует наличия готового PNG. Данные фида могут содержать пустые поля и `season: null`: перед отправкой в генератор заполните обязательные значения. Если нет обоих файлов, ответ `404` с кодом `parameters_not_found`. При ошибке чтения или разбора JSON — `500`, `parameters_read_failed`.

Повторная обработка фида не удаляет `generation-<theme>.json`: ручные параметры сохраняют приоритет в редакторе, даже если сама карточка уже перезаписана данными фида.

## 4. Генерация карточки

```http
POST /api/v1/cards/generate
X-API-Key: your-secret-api-key
Content-Type: application/json
```

Тело:

```json
{
  "theme": "dark",
  "sku": "S207352",
  "brand": "Cordiant",
  "model": "GRAVITY SUV",
  "size": "225/65 R17",
  "load_index": "106",
  "speed_index": "H",
  "image_url": "https://rest.mtkrosberg.ru/upload/iblock/ca0/3thwfmq12unxg0qeqke2h2fx4rqkq008.jpg",
  "season": "summer"
}
```

| Поле | Обязательно | Формат |
| --- | --- | --- |
| `theme` | да | `dark` или `light` |
| `sku` | да | Артикул, 1–100 латинских букв, цифр, `_` или `-`; служебные имена Windows запрещены |
| `brand` | да | Непустая строка от 1 до 100 символов |
| `model` | да | Непустая строка от 1 до 200 символов |
| `size` | да | Размер целиком, например `225/65 R17`, без индексов |
| `load_index` | да | Строка из 2–3 цифр, также допустимо `106/104` |
| `speed_index` | да | Строка из 1–3 латинских букв, например `H`, `V`, `ZR` |
| `image_url` | да | Публичная HTTP/HTTPS ссылка на JPEG, PNG или WebP |
| `season` | нет | `summer`, `winter`, `all-season` или `null`; без поля или при `null` подпись «ШИНЫ» |

Все поля, кроме `season`, обязательны. Неизвестные поля отклоняются. Индексы передавайте строками, например `"106"`, а не числом `106`.

Генерация синхронная: запрос ждёт скачивания фото и сборки карточки. Ответ `200 OK` возвращает ссылку на **готовый результат**, а не на исходное фото:

```json
{
  "sku": "S207352",
  "theme": "dark",
  "image_url": "https://tools.3sta.ru/images/dark/S207352.png?v=123"
}
```

Файл сохраняется в `<CARD_OUTPUT_DIR>/<theme>/<sku>.png`. Повторный запрос перезаписывает только выбранную тему; SKU не обязан заранее существовать в фиде. PNG публикуется атомарной заменой файла, затем отдельной операцией сохраняются параметры. Это не единая транзакция: если сохранение параметров завершится ошибкой, возможен ответ `500` при уже обновлённом PNG. При одновременной генерации одного артикула в одной теме файлы могут обновляться конкурирующими запросами; избегайте таких запросов.

Параметр `v` в ссылке вычисляется по времени изменения файла, это не ID задания и не история версий. Метод скачивания всегда отдаёт текущий файл, даже по старой ссылке с `v`. Для обхода кеша используйте ссылку из последнего ответа.

Исходное фото скачивается на время обработки и не сохраняется постоянно. Макет, удаление фона и обработка резкости общие с генератором фида. Лучше использовать фото на белом фоне. Различия в ракурсе и низкое исходное разрешение обработка полностью не устраняет.

## 5. Скачивание готового изображения

Откройте `image_url` из ответа списка, поиска или генерации обычным GET-запросом. Заголовок `X-API-Key` не нужен.

```http
GET /images/light/S207352.png?v=123
```

Ответ — PNG-файл с `Content-Type: image/png` и `Cache-Control: no-cache`. При отсутствии файла — `404`, `image_not_found`. Параметр `theme` находится в пути: только `dark` или `light`.

## Пример в Postman

Метод: **GET**. URL: `https://tools.3sta.ru/api/v1/cards?theme=light&page=1&per_page=10`.

В **Headers** добавьте `X-API-Key` с вашим ключом. Для генерации выберите **POST** и URL `https://tools.3sta.ru/api/v1/cards/generate`, затем **Body → raw → JSON** и вставьте тело из раздела 4. Полученную ссылку `image_url` откройте отдельным GET-запросом без ключа.

## Ошибки и ограничения

| HTTP | Причина |
| --- | --- |
| `401` | Неверный или отсутствующий `X-API-Key` |
| `503` | На сервере не настроен `CARD_API_KEY` |
| `404` | Карточка или сохранённые параметры отсутствуют |
| `413` | Исходное фото больше 30 МБ или 20 мегапикселей |
| `422` | Неверные/отсутствующие поля, некорректная ссылка, повреждённое фото или не удалось выделить товар |
| `429` | Уже идут две генерации; повторите запрос позже |
| `502` | Не удалось скачать фото или слишком много перенаправлений |
| `500` | Ошибка генерации, сохранения или чтения параметров |

Ошибки бизнес-логики содержат `detail.code` и `detail.message`. Ошибки проверки полей FastAPI содержат массив `detail` с путём поля и причиной. Ответы об ошибках не содержат ссылки на результат.

Для скачивания разрешены публичные адреса и порты 80/443. Локальные адреса и адреса внутренней сети запрещены, в том числе после перенаправления. Лимит перенаправлений — 5. Бюджет загрузки — 30 секунд, с проверкой между чтениями; медленное последнее чтение может дополнительно занять до одного сетевого тайм-аута. Генератор допускает две одновременные обработки на процесс, остальные получают `429`.

## Примеры PowerShell

```powershell
$baseUrl = "https://tools.3sta.ru"
$headers = @{ "X-API-Key" = "your-secret-api-key" }

# Список
Invoke-RestMethod "$baseUrl/api/v1/cards?theme=dark&page=1&per_page=100" -Headers $headers

# Один артикул
Invoke-RestMethod "$baseUrl/api/v1/cards/S207352?theme=dark" -Headers $headers

# Генерация
$body = @{
    theme = "dark"
    sku = "S207352"
    brand = "Cordiant"
    model = "GRAVITY SUV"
    size = "225/65 R17"
    load_index = "106"
    speed_index = "H"
    image_url = "https://rest.mtkrosberg.ru/upload/iblock/ca0/3thwfmq12unxg0qeqke2h2fx4rqkq008.jpg"
    season = "summer"
} | ConvertTo-Json

$result = Invoke-RestMethod "$baseUrl/api/v1/cards/generate" -Headers $headers -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body)) -TimeoutSec 180
$result.image_url
```

## Проверка API

```powershell
pip install -r requirements-dev.txt
python -m unittest test_api -v
```

Тесты проверяют список, фильтр темы, поиск/404, защиту API ключом, публичный интерфейс и перегенерацию без ключа, обязательные поля, запрет внутренних адресов, ссылки и сохранение результата. Они не обращаются к фиду и не генерируют реальные карточки.

Справка используемых инструментов: [FastAPI — обработка ошибок](https://fastapi.tiangolo.com/tutorial/handling-errors/), [Uvicorn — параметры запуска](https://www.uvicorn.org/settings/).
